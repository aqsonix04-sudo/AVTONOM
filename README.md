# Станция «Автоном»

**Станция «Автоном»** — стратегическая игра-симулятор строительства и управления автономной космической колонией.

Игрок развивает небольшую базу на ограниченном поле, размещает производственные и жилые модули и следит за запасами жизненно важных ресурсов. Главная задача — обеспечить колонию всем необходимым и выполнить поставленную цель.

## Игровой процесс

- Размещайте модули на свободных клетках игровой сетки.
- Следите за соединениями и работой установленных модулей.
- Производите и распределяйте ресурсы.
- Поддерживайте колонистов и расширяйте базу.
- Выполняйте цели до окончания отведённого времени.

## Ресурсы

В интерфейсе отображаются основные показатели колонии:

- **Энергия** — необходима для работы инфраструктуры.
- **Вода** — добывается и используется системами колонии.
- **Кислород** — поддерживает условия для жизни.
- **Еда** — обеспечивает колонистов питанием.

## Модули

По записи игрового процесса в панели строительства представлены следующие модули:

| Модуль | Назначение |
|---|---|
| Панель | Производство энергии |
| Ледобур | Добыча воды |
| Электролиз | Получение кислорода из воды |
| Ферма | Производство еды |
| Жильё | Размещение колонистов |
| Дрон-док | Инфраструктура для дронов |

Назначения приведены по названиям и интерфейсу игры; конкретные числовые характеристики модулей могут меняться.

## Управление

По показанной версии интерфейса:

- **Мышь** — выбор модулей, клеток и элементов интерфейса.
- **Пауза** — приостановка игрового процесса.
- **Панель строительства** — выбор модуля для размещения.

Точные клавиатурные сочетания в записи не подтверждены.

## Цель игры

Создать устойчивую колонию, в которой хватает энергии, воды, кислорода, еды и жилых мест, и выполнить игровое задание за отведённое время.
